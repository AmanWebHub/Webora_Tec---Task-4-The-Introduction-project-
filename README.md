# Simple JavaScript Form Validation

A simple, responsive contact form built with HTML, CSS, Bootstrap, and JavaScript. This project demonstrates basic client-side form validation and dynamic feedback using Bootstrap alerts.

## Features

- **Form Validation:** Checks whether the name, email, and message fields are empty.
- **Whitespace Handling:** Uses JavaScript's `trim()` method to prevent fields containing only spaces from passing validation.
- **Bootstrap Alerts:** Displays success and error messages directly on the webpage.
- **Input Focus:** Automatically focuses on the first field that requires attention.
- **Responsive Layout:** Uses Bootstrap styling for a clean and responsive form interface.

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.

### Installation

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your web browser.
4. Enter details into the form and click **Submit** to test the validation.

Through this project, I practised:

- Selecting HTML elements using JavaScript.

## Limitations

This project demonstrates client-side validation only. It does not send, store, or process submitted form data on a server.
